# Course scope and evidence

The team plan describes a software only AI2002 project using simulated NASA C-MAPSS FD001 histories. The current repository is a bootstrap preview. It contains no trained scientific models, official test metrics, scheduling results, report, slides, or verified public deployment. The official course statement was not available in this repository and must be checked by the team.

Human review is still needed for originality, scientific interpretation, justified assumptions, diagrams, report and slides, all member understanding, and the live demonstration. Automated inventory cannot certify those claims.
